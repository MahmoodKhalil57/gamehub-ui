# GameHub UI

Static frontend for GameHub — plain HTML/JS/CSS, served by GitHub Pages.
The backend (Postgres, Auth, Realtime, Row-Level Security) is Supabase; its schema
lives in [MahmoodKhalil57/gamehub](https://github.com/MahmoodKhalil57/gamehub).

Live: https://mahmoodkhalil57.github.io/gamehub-ui/

Run locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
